Entry 1: Learning Linux Fundamentals Date: November 17th, 2026 Topic: Linux Commands and System Navigation What I Learned:
Linux is an operating system that is used in many everyday technologies, including websites, servers, phones, and security systems. I learned that Linux is important in cybersecurity because many organizations use it to manage their systems and protect sensitive information.
Linux was created in 1991 by Linus Torvalds and has become a widely used open-source operating system. Open-source means its source code is available for people to view, modify, and improve.
I also learned that Linux uses a terminal, which allows users to communicate with the computer by typing commands instead of clicking with a mouse. Some basic commands include:
•	whoami: Shows the current username.
•	pwd: Shows the current directory.
•	ls: Lists files and folders.
•	cd: Changes directories.
•	cat: Displays the contents of a file.
•	echo: Displays text in the terminal.
Why This Matters in Cybersecurity:
Understanding Linux is important because cybersecurity professionals use it to investigate security threats, manage files, review system activity, and troubleshoot problems. Knowing how to navigate Linux will help me become more comfortable working with security tools and investigating potential threats.
My Takeaway:
My biggest takeaway is that learning basic Linux commands is the foundation for understanding how computer systems operate. Although the terminal can seem intimidating at first, practicing commands will help me become more confident as I continue learning cybersecurity.

Entry 2: Intro To Logs Date: November 17th, 2026 Topic: 
Intro to Logs – Tasks 1–3
What I Learned:
Logs are records of activities that happen within a computer, network, or application. They help cybersecurity professionals understand what happened on a system, when it happened, and whether any suspicious activity occurred.
I learned that logs are important because they provide historical evidence that can help investigators identify security incidents. For example, logs can show failed login attempts, unauthorized access, system errors, and unusual network activity.
There are several types of logs, including:
•	System Logs: Record operating system activities and errors.
•	Security Logs: Track security-related events such as login attempts and permission changes.
•	Application Logs: Record activities and errors within applications.
•	Network Logs: Track network connections and traffic.
•	Web Server Logs: Record requests made to websites.
•	Audit Logs: Track activities that may need to be reviewed for security and compliance.
New Terms I Learned:
•	Log Analysis: Reviewing log records to identify patterns, errors, or suspicious activities.
•	Timestamp: The date and time an event occurred.
•	Event: An activity recorded by a system.
•	Incident Response: The process of investigating and responding to security threats.
•	Log Format: The way information is organized within a log file.
How Logs Connect to Linux:
Linux and logs work together because Linux systems generate records of system activities. Using Linux commands such as cat and grep, cybersecurity professionals can read log files and search for important information.
For example, if someone attempts to access a system without permission, security logs may contain evidence of those attempts. A cybersecurity analyst can use Linux commands to review the records and investigate what happened.
Why This Matters in Cybersecurity:
Logs help security professionals detect attacks, investigate incidents, and protect organizations from future threats. They are also important for governance, risk, and compliance because organizations need accurate records to support audits and demonstrate that security procedures are being followed.
My Takeaway:
My biggest takeaway is that logs tell the story of what happened on a computer system. Learning how to read and understand them will help me identify suspicious activity and better understand how cybersecurity investigations work. I can also see how Linux skills and log analysis connect because both are important for monitoring and protecting systems.
