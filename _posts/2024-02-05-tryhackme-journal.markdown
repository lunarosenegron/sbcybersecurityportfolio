Entry 1: Learning Linux Fundamentals Date: November 17th, 2026 Topic: Linux Commands and System Navigation What I Learned:
Linux is an operating system that is used in many everyday technologies, including websites, servers, phones, and security systems. I learned that Linux is important in cybersecurity because many organizations use it to manage their systems and protect sensitive information.
Linux was created in 1991 by Linus Torvalds and has become a widely used open-source operating system. Open-source means its source code is available for people to view, modify, and improve.
I also learned that Linux uses a terminal, which allows users to communicate with the computer by typing commands instead of clicking with a mouse. Some basic commands include:
•	whoami: Shows the current username.
•	pwd: Shows the current directory.
•	ls: Lists files and folders.
•	cd: Changes directories.
•	cat: Displays the contents of a file.
•	echo: Displays text in the terminal.
Why This Matters in Cybersecurity:
Understanding Linux is important because cybersecurity professionals use it to investigate security threats, manage files, review system activity, and troubleshoot problems. Knowing how to navigate Linux will help me become more comfortable working with security tools and investigating potential threats.
My Takeaway:
My biggest takeaway is that learning basic Linux commands is the foundation for understanding how computer systems operate. Although the terminal can seem intimidating at first, practicing commands will help me become more confident as I continue learning cybersecurity.
